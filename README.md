# Milo’s Midnight Dash

Milo is a mustached ginger cat on a midnight rooftop run. Jump over chimneys, beat your last score, and watch for meteors, UFOs, a jetpack alien, and a manananggal in the night sky.

## How to Play

- Milo walks automatically as the rooftops scroll past.
- Press **Space** to jump over chimneys.
- Your score increases with distance, and the game speeds up as you go.
- If Milo hits a chimney, press **Space** to try again.

## Features

- A four-frame walk cycle for Milo
- Alternating brick and teal rooftops with glowing windows
- A pixel-art skyline that scrolls more slowly than the rooftops
- Four flying characters and objects that loop across the sky

## Open the Project in Unity

1. On GitHub, click **Code → Download ZIP**, then extract the ZIP.
2. In Unity Hub, add the extracted folder that contains `Assets`, `Packages`, and `ProjectSettings`.
3. Open the project with **Unity 6.3 LTS**. It was developed in **6000.3.28f1**.
4. In Unity’s Project panel, open `Assets/Rooftop.unity`.
5. Click **Play**, then click inside the **Game** tab and press **Space** to jump.
